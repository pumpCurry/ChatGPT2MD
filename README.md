# ChatGPT2MD & Codex2md (English)

This JavaScript toolset allows you to scrape and download ChatGPT conversation logs and Codex execution results in Markdown format simply by pasting and running it in your browser's developer tools (Console).

## Included Scripts

### 1. ChatGPT2MD.js
Exports ChatGPT conversation threads as Markdown files.
- **Features**:
  - Neatly formats user-AI conversations.
  - **Preserves thought processes**: Detects “Thought/Leading” from newer models (like o1) and saves them as separate `<details>` footnotes, allowing you to review the thought process without compromising readability.
  - Maintains code blocks and table structures.

### 2. Codex2md.js
Extracts task version changes (Patches) and prompts as Markdown from Codex (AI programming tool) execution results screens.
- **Features**:
  - Retrieves multiple versions (Version 1, 2...) collectively.
  - Automatically captures `git diff`-style patches for each file via the clipboard and embeds them into Markdown.
  - **Optimized for code review with Gemini, etc.**: The generated Markdown serves as highly effective material when requesting code reviews from LLMs.

---

## Usage

No special installation required. Works entirely within your browser.

1. Select and copy the entire code of the desired `.js` file (`ChatGPT2MD.js` or `Codex2md.js`) from this repository.
2. Open the target page (a ChatGPT thread or a Codex task screen).
3. Open your browser's **Developer Tools**.
   - *Windows/Linux*: `F12` or `Ctrl` + `Shift` + `I`
   - *Mac*: `Cmd` + `Opt` + `I`
4. Select the **Console** tab.
5. Paste the copied code and press the `Enter` key to execute it.
6. Scraping will start automatically. Once complete, a Markdown file (`.md`) will be downloaded.

## Advanced Code Review Using Gemini (Codex2md)

Markdown files generated by `Codex2md.js` are extremely effective when using LLMs like Google Gemini for code review.

### Procedure
1. Download the Codex results as a `.md` file using `Codex2md.js`.
2. Open Gemini (or AI Studio).
3. Attach the downloaded `.md` file.
   - ※ For higher accuracy, optionally set the repository's code via “+ icon > Import code”.
4. Request a review using the following prompt.


### Recommended Prompt

This enables advanced comparative analysis beyond simple diff checks, incorporating suitability against the requirements definition (proposition) and implementation coverage rate.

```
Which one adheres to the proposition while making appropriate modifications based on nuance and specifications?

I want to apply the patch described in the attached text to the repo and evaluate its quality.
Evaluate each candidate based on the text's proposition, including the patch described in the text.
For the log of the planned pull request described in the text, tell me which one best fits the proposition,
along with the reason, the implementation coverage rate for the evaluation points,
and the differences between each version candidate.
(Please also calculate the implementation coverage rate for evaluation points
 and provide reasons for candidates not selected.)
```

# ChatGPT2MD & Codex2md (日本語)

ブラウザの開発者ツール（Console）に貼り付けて実行するだけで、ChatGPTの会話ログやCodexの実施結果をMarkdown形式でスクレイピング・ダウンロードできるJavaScriptツールセットです。

## 収録スクリプト

### 1. ChatGPT2MD.js
ChatGPTの会話スレッドをMarkdownファイルとしてエクスポートします。
- **特徴**:
  - ユーザーとAIの会話をきれいに整形。
  - **思考プロセスの保持**: 新しいモデル（o1など）の「思考時間（Thought/Leading）」を検出し、本文とは別の `<details>` 脚注として保存するため、読みやすさを損なわずに思考過程を確認できます。
  - コードブロックやテーブル構造も維持されます。

### 2. Codex2md.js
Codex (AIプログラミングツール) の実施結果画面から、タスクのバージョンごとの変更差分（Patch）やプロンプトをMarkdownとして抽出します。
- **特徴**:
  - 複数のバージョン（Version 1, 2...）をまとめて取得。
  - 各ファイルの `git diff` 形式のパッチを自動でクリップボード経由で取得し、Markdownに埋め込みます。
  - **Gemini 等でのコードレビューに最適化**: 出力されたMarkdownは、LLMにコードレビューを依頼する際の資料として非常に強力です。

---

## 使い方 (Usage)

特別なインストールは不要です。ブラウザのみで完結します。

1. このリポジトリから使用したい `.js` ファイル（`ChatGPT2MD.js` または `Codex2md.js`）のコードを全選択してコピーします。
2. 対象のページ（ChatGPTのスレッド、またはCodexのタスク画面）を開きます。
3. ブラウザの **開発者ツール (Developer Tools)** を開きます。
   - *Windows/Linux*: `F12` または `Ctrl` + `Shift` + `I`
   - *Mac*: `Cmd` + `Opt` + `I`
4. **Console** タブを選択します。
5. コピーしたコードを貼り付け、`Enter` キーを押して実行します。
6. 自動的にスクレイピングが始まり、完了するとMarkdownファイル (`.md`) がダウンロードされます。

## Gemini を活用した高度なコードレビュー (Codex2md)

`Codex2md.js` で生成されたMarkdownファイルは、Google Gemini などのLLMにコードレビューさせる際に絶大な効果を発揮します。

### 手順
1. `Codex2md.js` でCodexの結果を `.md` ファイルとしてダウンロードする。
2. Gemini (または AI Studio) を開く。
3. ダウンロードした `.md` ファイルを添付する。
   - ※ 必要に応じてリポジトリのコードも「＋アイコン > コードをインポート」からセットするとより精度が上がります。
4. 以下のプロンプトを使用してレビューを依頼する。

### 推奨プロンプト

```text
命題に従いつつも、ニュアンスと仕様により適切な修正をおこなっているものはどれか

repoに対し、添付テキストに書かれたパッチを当てたく、出来の評価をしたい。 テキストの命題に沿って テキストに記載されたパッチについても各候補を評価して。
テキストに記載されたプルリクエスト予定のログに対して、命題に対してどれが一番適合しているか、
その理由と、評価ポイントに対する実装カバレッジ率と、各バージョン候補の違いについて教えて。
（選ばれなかった候補についても理由と評価ポイントに対する実装カバレッジ率を算定してください）
```

これにより、単なる差分確認だけでなく、要件定義（命題）に対する適合度や実装カバレッジ率を含めた高度な比較検討が容易になります。
